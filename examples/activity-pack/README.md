# Activity - a Vizstrap package

Adds an **Activity** tab to Vizstrap's settings: how long you played which game today, this week and in all, with a
chart of the last 7 days, the games' names and icons and a **Play** button.

The package is one small file: [`pages/activity.xml`](pages/activity.xml). It puts Vizstrap's activity widgets on a tab
and adds a switch that hides the chart - a good start for a tab of your own.

Vizstrap counts play time from Roblox's logs whether this package is on or not, so switching it on shows your history
straight away. Nothing leaves your computer.

See [Making a package](../../docs/making-a-package.md) for everything a tab can hold.
