# 📚 Vizstrap guides

Everything you can make for Vizstrap, step by step.

| Guide | What you'll make |
|---|---|
| 📦 [**Making a package**](making-a-package.md) | A `.vzmod` package: your own **tabs** in the settings with switches, sliders, lists and text fields, translations, and how to share it |
| 🌈 [**Making shaders**](making-shaders.md) | Picture effects over the game in HLSL, with sliders - 8 ready examples from a tint to outlines |
| 🔌 [**Making programs**](making-programs.md) | A program in any language that starts with Roblox, reads your tab's settings and sends notifications |
| 🎨 [**Making loading themes**](making-loading-themes.md) | Your own loading window in Bloxstrap's XML format: layout, colours, gradients, effects |
| 📁 [**Replacing game files**](making-mods.md) | Cursors, sounds, emoji and fonts - where Roblox keeps them and how to swap them |

Examples to open and change: [`examples/activity-pack`](../examples/activity-pack) (a tab made of widgets) and
[`examples/synthwave-pack`](../examples/synthwave-pack) (a cursor, 3 shaders, a loading theme and a program).
